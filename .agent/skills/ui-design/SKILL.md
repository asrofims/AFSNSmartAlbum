# UI Design Skill

## Purpose
Keep the entire application visually modern, professional, consistent, and appropriate for desktop creative work.

## Direction
AFSNSmartAlbum should feel like professional creative software, not a SaaS dashboard.

Prioritize:
- photo visibility
- workspace clarity
- fast interaction
- predictable panels
- strong hierarchy
- minimal visual noise

Avoid:
- generic dashboard cards
- excessive rounded cards
- excessive gradients
- random colors
- decorative UI
- oversized controls
- unnecessary dialogs

## Workspace
Use a clear editor workspace with toolbar, photo library, canvas, properties/settings, and page/status navigation.

## Design System
Use centralized tokens for typography, spacing, colors, radius, borders, shadows, and states.

Preferred spacing:
4 / 8 / 12 / 16 / 24 / 32

## Components
Reuse existing components before creating new ones:
Button, IconButton, Toolbar, Panel, PanelHeader, Input, NumberInput, UnitInput, Select, ColorPicker, Dialog, Tabs, Tooltip, ContextMenu, StatusBar.

## Interaction
Desktop-first:
- mouse
- keyboard
- drag & drop
- context menus
- predictable shortcuts

Icon-only controls need tooltip/accessibility labels.

## Theme
Prioritize a professional dark workspace. Use shared tokens for light mode if supported.

## Definition of Done
UI must follow the design system, reuse components, avoid random styles, support desktop window sizes, and provide clear interaction feedback.
