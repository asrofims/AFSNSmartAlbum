## Design albums and social content locally

AFSNSmartAlbum combines precise album-spread tools with a dedicated single-page Social Media mode. Photos remain on your computer while you design, save, and export production-ready projects.

| Photo Album | Social Media |
| :--- | :--- |
| Professional layflat spreads with Left Page, Center Gutter/Spine, and Right Page geometry. | Single-post canvases with independent dimensions for each post. |
| Accurate `mm`, `cm`, `inch`, and `px` units at the configured project DPI. | Presets for Instagram, Facebook, Pinterest, YouTube, TikTok, and LinkedIn. |
| Bleed-aware full-spread and split-page export. | Adaptive layouts and four-sided Safe Zone Margins. |

## Highlights

- Adaptive photo layouts that respect Safe Zone Margins, spacing, crops, and locked objects
- Non-destructive photo crop, pan, zoom, replacement, and swapping
- Smart magnetic snapping, alignment, grouping, locking, and layer ordering
- Rich text frames with typography presets and styled ranges
- Dynamic per-post canvas sizes for Social Media projects
- High-resolution JPEG, PNG, and PDF export
- Portable `.afsn` projects, recovery snapshots, and guarded file replacement
- Local-first workflow with no cloud upload requirement for editing or export

## Download and updates

Download the current Windows installer from [GitHub Releases](https://github.com/asrofims/AFSNSmartAlbum/releases/latest).

Installed versions can use **About AFSNSmartAlbum → Check Updates**. Update packages are cryptographically signed and verified by the application before installation.

This public repository is the official binary release channel. Application source and development history are maintained privately.
